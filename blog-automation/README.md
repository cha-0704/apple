# ソウル美容ノート 자동 초안 시스템

구글 시트에 주제를 적어 두면, **매일 1편씩** Claude가 일본어 글을 쓰고 Blogger에 **임시저장(초안)**으로 올려 줍니다. 초안이 완성되면 메일로 알려 줍니다.

> 자동으로 **공개하지는 않습니다.** 차대표님이 확인하고 직접 「公開」를 눌러야 올라갑니다. 티스토리 정지와 애드센스 품질 문제를 피하기 위한 안전장치입니다.

## 동작 방식

```
[1시간마다 자동 실행]
  ① 시트에서 아직 처리 안 한 주제 1개 선택 (하루 1개)
  ② Claude Batch API로 글 생성 요청 (일반 요청보다 50% 저렴)
  ③ 생성이 끝나면 Blogger에 초안으로 저장
  ④ 메일 알림: 초안 링크 + 퍼머링크 + 검색 설명 + 수정할 곳 개수
```

## 글 품질 안전장치

- 시트 B열(메모)에 적지 않은 **통계·금액·순위는 지어내지 않고** 빨간 `【要確認】`로 비워 둡니다.
- 소니의 **경험담도 지어내지 않고** 빨간 `【要編集】`로 비워 둡니다.
- 사진 넣을 위치는 회색 `【写真】`로 표시합니다.
- 특정 병원·상품 홍보, 제휴 링크는 넣지 않습니다.

## 설치 (처음 한 번, 약 15분)

### 1. Claude API 키 만들기
1. https://console.anthropic.com 에 가입하고 결제 수단을 등록합니다 (선불 크레딧).
2. **API Keys → Create Key** 로 키를 만들고 복사해 둡니다. 키는 비밀번호처럼 다루세요.

### 2. 블로그 ID 확인
Blogger 관리 화면에서 「ソウル美容ノート」를 열면 주소창이 이렇게 보입니다.
```
https://www.blogger.com/blog/posts/1234567890123456789
```
마지막 긴 숫자가 **블로그 ID**입니다.

### 3. 구글 시트 + Apps Script 만들기
1. 새 구글 시트를 만듭니다 (이름 예: `ソウル美容ノート 자동화`).
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 왼쪽 **프로젝트 설정(톱니바퀴)** → 「편집기에 appsscript.json 매니페스트 파일 표시」 체크.
4. 편집기에서 `Code.gs` 내용을 지우고 이 폴더의 [`Code.gs`](Code.gs) 전체를 붙여넣습니다.
5. `appsscript.json` 내용을 이 폴더의 [`appsscript.json`](appsscript.json) 으로 바꿉니다.
6. **프로젝트 설정 → 스크립트 속성** 에 3개를 추가합니다.

| 속성 | 값 |
|---|---|
| `ANTHROPIC_API_KEY` | 1번에서 만든 키 |
| `BLOG_ID` | 2번의 숫자 |
| `NOTIFY_EMAIL` | 알림 받을 메일 (비워 두면 내 구글 계정) |

7. 편집기 위쪽 함수 목록에서 **`setup`** 선택 → **실행** → 권한 승인 (Blogger, 시트, 메일, 외부 요청).

### 4. 주제 넣기
시트의 `keywords` 탭에 이렇게 적습니다.

| A: 키워드 / 테마 | B: 메모 (사실·체험) |
|---|---|
| オリーブヤングで買うべき皮膚科コスメ | 지난주 명동점에서 ○○ 크림을 샀는데 촉촉했음 |
| 聖水（ソンス）のおしゃれカフェ巡り | |
| 韓国の免税手続きのやり方 | 2026년 기준 즉시환급 한도는 직접 확인 후 기입 |

B열에 적은 내용만 사실로 사용합니다. **진짜 경험 한 줄**을 적어 두면 글이 훨씬 좋아집니다.

### 5. 바로 테스트
함수 목록에서 **`runNow`** 실행 → 1~2시간 안에 초안과 메일이 옵니다. (Batch는 보통 1시간 안에 끝나지만 최대 24시간까지 걸릴 수 있습니다.)

## 매일 할 일 (5~10분)

1. 메일의 초안 링크 열기
2. 빨간 `【要確認】` `【要編集】` 고치기, 사진 넣기
3. 오른쪽 설정에 메일에 적힌 **퍼머링크**와 **검색 설명** 입력
4. 읽어 보고 「公開」

## 비용 (추정)

- 모델: Claude Opus 5.5 (입력 $4 / 출력 $20 per 100만 토큰), Batch API로 50% 할인
- 글 1편 ≈ 입력 2천 + 출력 약 1만 토큰(생각 과정 포함) → **약 $0.1 안팎**
- 하루 1편 × 30일 ≈ **월 $3 안팎**

실제 금액은 글 길이에 따라 달라집니다. console.anthropic.com 의 Usage 화면에서 확인하세요.

## 설정 바꾸기 (`Code.gs` 맨 위)

| 상수 | 기본값 | 설명 |
|---|---|---|
| `POSTS_PER_DAY` | `1` | 하루 초안 개수. 1~3을 권장합니다 |
| `EFFORT` | `'medium'` | 글 품질/비용. `'high'`로 올리면 더 꼼꼼하지만 비싸집니다 |
| `MODEL` | `'claude-opus-5-5'` | 사용할 Claude 모델 |

## 참고

- 거절(refusal) 대비로 서버 측 대체 모델 기능(`fallbacks: "default"`)을 켜 두었습니다. 배치에서 지원되지 않으면 자동으로 끄고 다시 보냅니다.
- 시트의 `상태` 열: `QUEUED`(생성 중) → `DRAFTED`(초안 완료) / `ERROR`(실패, 이유는 E열). `ERROR` 행은 C~F열을 지우면 다시 시도합니다.

## 문제 해결

| 증상 | 해결 |
|---|---|
| `Blogger への保存に失敗 … API has not been used` | 오류 메시지 속 링크로 Blogger API를 사용 설정. 안 되면 Google Cloud 프로젝트를 만들어 Blogger API를 켜고, Apps Script 프로젝트 설정에서 그 프로젝트 번호로 바꿉니다 |
| `Claude API エラー 401` | `ANTHROPIC_API_KEY` 확인 |
| `Claude API エラー 400 … credit` | Anthropic 콘솔에서 크레딧 충전 |
| 메일이 안 옴 | 시트의 상태 열 확인. `QUEUED`면 아직 생성 중입니다 |

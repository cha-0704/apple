# 무료 · 상업적 이용 가능 · 내 컴퓨터에서 가볍게 돌아가는 한국어 TTS

> 기준: ① 한국어 지원 ② 무료 ③ 수익화 유튜브에 써도 되는 라이선스 ④ GPU 없이 일반 PC/노트북 CPU로 실시간 이상
> 라이선스는 바뀔 수 있으니, 수익화 전에 각 모델 페이지의 LICENSE를 한 번 더 확인하세요.

## 1순위 — Supertonic 3 (Supertone, 한국 회사) ✅ 이번 프로젝트 채택

| 항목 | 내용 |
|---|---|
| 한국어 | 지원 (v3 기준 31개 언어) |
| 라이선스 | 코드 MIT / 모델 OpenRAIL-M → 상업적 이용 가능 (불법·기만·혐오 용도 금지 같은 사용 제한 조항만 지키면 됨) |
| 용량 | ONNX 4개 + 보이스 파일, 합계 약 145MB |
| 속도 | ONNX Runtime CPU로 실시간보다 훨씬 빠름 (온디바이스 설계) |
| 목소리 | 기본 보이스 10종: 여성 F1~F5, 남성 M1~M5 (`ko_F1`처럼 언어 + 보이스로 지정) |
| 설치 | `pip install supertonic` (첫 실행 시 Hugging Face에서 모델 자동 다운로드) |
| 장점 | 가볍고 빠름, 설치가 쉬움, 속도(speed) 조절 가능, 숫자·단위 읽기 처리 |
| 주의 | 감정 연기는 약한 편 → 지식·정보 채널 내레이션에 딱 맞음 |

## 대안

| 모델 | 한국어 | 라이선스 | 가벼움 | 한 줄 평 |
|---|---|---|---|---|
| MeloTTS (MyShell) | ✅ | MIT | CPU 실시간 | 한국어 화자 1명. 무난하지만 Supertonic보다 단조로움 |
| GPT-SoVITS | ✅ | MIT | GPU 권장 | 내 목소리 복제용. 1분 녹음으로 학습. 본인 목소리일 때만 쓸 것 |
| CosyVoice 2 | ✅ | Apache-2.0 | 무거움(GPU) | 품질 좋지만 "가볍게"는 아님 |

## 피해야 할 것 (무료지만 상업 이용에 위험)

- **Edge-TTS(MS 온라인 음성)**: 무료로 쓸 수는 있지만 공식 상업 이용 라이선스가 아님 → 수익화 채널엔 비추천
- **Coqui XTTS-v2**: CPML 라이선스, 비상업용
- **Fish Speech 공개 가중치**: CC BY-NC-SA, 비상업용
- **Kokoro-82M**: Apache-2.0이라 상업 이용은 되지만, 한국어 미지원

## 결론

지식·정보 롱폼 내레이션은 **Supertonic 3**. 속도·톤이 안정적이라 10분 넘는 롱폼도 일정하게 읽고,
CPU만으로 1분짜리 음성을 몇 초 안에 만들어서 대본 수정 → 재생성 루프가 빠릅니다.

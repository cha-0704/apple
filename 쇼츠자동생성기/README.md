# 🏭 쇼츠 공장

주제 하나를 넣으면 **대본, 장면별 이미지·모션 프롬프트, 썸네일 문구**를 한 번에 만들어 주는 Gemini 기반 생성기예요.

| 채널 | 콘셉트 |
|---|---|
| 🤖 신비한 기계사전 | 피지컬 AI, 로봇, 자동화의 속을 3D 단면으로 보여 줌 |
| ⚛️ 일상 속 물리 단면 | 매일 쓰는 물건 속 물리 현상을 3D 단면으로 보여 줌 |

## 만들어 주는 것
- 훅 1문장, 제목 후보 5개
- 썸네일 문구 3세트 (큰 글씨, 작은 글씨, 강조 요소, 배경 이미지 프롬프트)
- 장면별 대본: 시간, 내레이션, 화면 자막, **영어 이미지 프롬프트**(Gemini 이미지·Midjourney용), **영어 모션 프롬프트**(Veo·Kling용), 효과음
- 설명란, 해시태그
- ✅ 업로드 전에 직접 확인할 사실 목록
- `.md`, `.json` 다운로드, 최근 30개 생성 기록

## 실행 방법

```bash
cd 쇼츠자동생성기
npm install
npm run dev
```

1. 브라우저에서 ⚙️ **API 설정**을 열고 [Google AI Studio](https://aistudio.google.com/apikey)에서 받은 키를 넣어요.
2. 채널과 포맷(쇼츠 40초 또는 롱폼 8~10분)을 고르고, 주제를 입력해요. 주제가 없으면 **💡 주제 10개 추천**을 눌러요.
3. **🚀 제작 패키지 생성**을 누르면 끝이에요.

모델은 기본이 `gemini-2.5-flash`이고, 설정 칸에서 다른 Gemini 모델 이름으로 바꿀 수 있어요.

## 여러 주제를 한 번에 만들기 (배치)

```bash
cp topics.example.txt topics.txt   # 한 줄에 주제 하나
GEMINI_API_KEY=내키 npm run batch -- topics.txt --channel machine --format shorts
```

결과는 `output/` 폴더에 주제별 `.md`와 `.json`으로 저장돼요. 실패한 주제는 건너뛰고 나머지는 계속 진행해요.

## 안티그래비티에서 쓰기
`.agent/skills/shorts-factory/SKILL.md`에 스킬이 들어 있어요. 안티그래비티 에이전트에게 "쇼츠 만들어", "주제 추천해 줘", "topics.txt로 배치 생성해 줘"라고 말하면 이 스킬을 따라 동작해요.

## ⚠️ 주의
- **API 키는 공개 배포하면 안 돼요.** `.env.local`의 `VITE_GEMINI_API_KEY`는 빌드 결과물에 그대로 들어가요. Netlify 같은 곳에 공개로 올릴 땐 키를 넣지 말고, 각자 화면에서 입력하게 두세요.
- AI가 만든 숫자와 사실은 틀릴 수 있어요. 사실 확인 목록은 꼭 직접 확인하세요.
- 유튜브는 대량 생산된 반복형 AI 콘텐츠의 수익 창출을 제한해요. 생성된 대본에 **차대표님만의 관점과 목소리**를 더해 주세요.

## 파일 구조
```
src/channels.js   채널 콘셉트, 3D 스타일 문구, 포맷 정의 (여기만 바꾸면 새 채널 추가)
src/prompts.js    프롬프트, 응답 스키마, 마크다운 변환
src/gemini.js     Gemini REST 호출 (브라우저와 Node 공용)
src/main.js       웹 화면
scripts/batch.mjs 배치 생성 CLI
```
